现场说明

没装 rosbridge 怎么起
机载 Jetson 上一条命令： 
sudo apt install -y ros-noetic-rosbridge-suite
roslaunch rosbridge_server rosbridge_websocket.launch
默认端口 9090，rosapi 会一起起来，本页面的参数读取依赖它。
第一次上真机的验证顺序
狗架空、四腿悬空，人守在遥控器旁。按这个顺序点： 
1. 诊断          -> 四个服务都在、enable_actuation 读到 false
2. 切回 Trot     -> 期望 message 里 code = 0，说明 1011 通了
3. 上行爬楼      -> 期望 SwitchGait(3) -> 0
第 1 步就要先看 enable_actuation。它是 false 时节点会直接拒绝， 返回 "enable_actuation is false"，狗完全不动——这正好用来确认链路通不通， 又不用担心它真迈腿。
确认 ID 无误后再用 _enable_actuation:=true 重启节点，才真的会切步态。
返回码怎么看
0 成功。非 0 是 SDK 的 RPC 返回码，说明指令没被接受， 最可能是 ID 在你这版固件上不是 1011/1049。
页面里 success=false 也会记一条红色日志，别只看颜色，要读 message。
为什么不放"急停"按钮
急停要走固件自己的阻尼/保护通道，这条路没在 stair_gait 里打通， 本页面硬造一个反而危险。切回 Trot 只是恢复常规步态，不是急停手段。 真出事按遥控器。
